# Assets
The resources in this folder are the same as those in our [Media Kit](https://katorly.com/mediakit).

You may use these resources by linking to them in your project, such as in a README file or on a website.

Please make sure to follow our [Brand Guidelines](https://lab.katorly.com/MediaKit/#guidelines) when using these assets.

## Usage
Take `mark.png` as an example. You can link to it in the following ways:

### GitHub blobs
```
https://github.com/katorlys/.github/blob/main/assets/mark/mark.png
```

### GitHub raw
```
https://raw.githubusercontent.com/katorlys/.github/main/assets/mark/mark.png
```

### jsDelivr
```
https://cdn.jsdelivr.net/gh/katorlys/.github/assets/mark/mark.png
```

### katorly.com
Omit the asset folder from the path.
```
https://katorly.com/static/mark.png
```
